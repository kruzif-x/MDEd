# Release Notes

This document describes the current release of the widget.

## Overview

The widget ships with three modes: fast, balanced, and thorough. Most users should start
with the balanced mode, which is a good default for everyday work.

## Features

- Fast startup time
- Configurable color themes
- Works offline

## Known Issues

- Occasionally the status bar flickers on resize.
- Large files (over 50MB) may load slowly.

## Installation

Download the installer and run it. Restart your computer afterward.

## Support

Please file bugs on the tracker. We read every report within a week.
