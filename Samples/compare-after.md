# Release Notes

This document describes the current release of the widget.

## Overview

The widget ships with three modes: fast, balanced, and thorough. Most users should start
with the fast mode, which is a good default for everyday work on modern hardware.

## Features

- Fast startup time
- Configurable color themes
- Works offline
- Built-in crash reporting

## Known Issues

- Large files (over 50MB) may load slowly.

## Installation

Download the installer and run it. No restart is required.

## Support

Please file bugs on the tracker. We read every report within two business days.
