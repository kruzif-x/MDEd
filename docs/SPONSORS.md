# GitHub Sponsors application kit — copy-paste ready for github.com/sponsors

## Profile description (short bio shown on your Sponsors page)
"Independent macOS developer building local-first AI tools: LM Switcher (menu-bar
LLM manager) and MDEd (Markdown editor with on-device AI). Everything is local,
everything is open source."

## Tier 1 — Coffee (recommended: USD 3/month)
"Thanks for the coffee! You support continued development of LM Switcher and MDEd."

## Tier 2 — Supporter (recommended: USD 8/month)
"Supporter badge: your name on the project READMEs, and early access to beta
builds before release."

## Tier 3 — Backer (recommended: USD 20/month)
"Backer badge plus priority: feature requests get answered first, and you get a
direct line for bugs and questions."

## One-time donations
GitHub Sponsors supports one-time payments natively (no third party needed) —
set a one-time amount alongside the monthly tiers, e.g. USD 5 / 10 / 25 presets.
Personal-account sponsorships carry no fee: 100% reaches you.

## FAQ (auto-asked by the application form)
- Region: Singapore
- 2FA: enabled (required — enable at github.com/settings/security if not already)
- Payout: Stripe (you'll set this up during application — needs bank details)
- Profile: public, no ToS violations

## Steps (yours, ~10 min)
1. https://github.com/sponsors → "Become a sponsor" / apply as individual
2. Confirm region (Singapore is supported), connect Stripe, add bank details
3. Paste the description + tiers above
4. Submit; approval is usually 1–3 business days
5. Once live, the Sponsor button appears automatically on MDEd (public repo)
   and everywhere your profile shows; lm-switcher's button appears when its
   GitHub repo goes public (its DMG release is private for now)
